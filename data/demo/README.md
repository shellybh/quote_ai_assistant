# נתוני הדמה

| קובץ | מה יש בו | מקור |
|---|---|---|
| `catalog.json` | 471 סעיפים: קוד, תיאור, יחידה, מחיר, פרק | **מחירון פומבי** לעבודות שימור (5.1.2023), בלי שינוי. בעל העסק אישר שימוש בו ב-28.10.2026 |
| `conditions.json` | 16 תנאים, לכל אחד `key` קבוע שהכללים משתמשים בו | **בדיוני**, נכתב לפרויקט |
| `proposals.json` | 30 הצעות קודמות (סעיפים, תנאים, אבני תשלום) | **בדיוני**: לקוחות "לקוח דמו NN", כתובות ב"עיר לדוגמה", כמויות ומחירים שהוגרלו סביב מחיר המחירון (0.85–1.16) |

**שום דבר כאן לא נלקח מהצעות אמיתיות, מלקוחות אמיתיים או מנוסחי התנאים של בעל העסק.**

## בנייה מחדש
```bash
python scripts/import_catalog_csv.py <path/to/price_list.csv>   # catalog.json
python scripts/build_demo_data.py                              # conditions + proposals (fixed seed)
python scripts/check_demo_data.py                              # stage-0 check: loads, no problems
```

## הערות
- שמות השדות תואמים לטבלאות של האפליקציה, כדי שבשלב 3 אותם נתונים יהפכו לקובץ הגיבוי של אפליקציית הדמו.
  שדות נוספים שאין באפליקציה: `key` בתנאים, `work_types` ו-`exterior_work` בהצעות.
- בהצעות אין סכומים, כי הסכומים מחושבים רק באפליקציה.
- ארבעה סעיפים במחירון (`01.11.001.0120`–`0150`, ציורי קיר) הם תבניות עם מחיר 0, ולכן הם לא נכנסים להצעות.
- **במחירון אין סעיף פיגום.** הפיגום מופיע רק כתנאי: "כלול" או "לא כלול".
